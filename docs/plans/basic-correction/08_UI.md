# 08 · UI, entry points, config

**Goal:** make Basic Correction usable from the three places in the concept (§9), with settings in the config
(§10).

## Tasks

1. **Config:** a `[basic_correction]` section in `config/workflow.toml` with the defaults from the concept.
   `config.py` reads it; missing keys fall back to the defaults, so older user configs keep working.
2. **Flow:** `davigen/basic/run.py`:
   - `basic_correction(resolve, cfg, rep, timeline=None, dry_run=False, recompute=False)`
   - Steps: `sample → measure → correct → scenes → write → save`, each a `Reporter` step, like the flows in
     `creator.py`.
3. **Server:**
   - `POST /api/basic` starts the flow (through `App._start`, as `/api/assign` does).
   - `GET /api/basic/report` returns the last record for the current timeline.
4. **Home screen** (`ui/index.html`, `ui/app.js`):
   - A **Basic correction** button next to *Assign groups & nodes*, with the options *Dry run* and
     *Recompute all*.
   - The report table: clip, confidence, stops, CCT before/after, contrast, sat, flags, sorted by confidence.
     Flagged rows first.
   - A click on a row sets Resolve to that clip (`Timeline.SetCurrentTimecode`, then `OpenPage("color")`).
5. **Wizard:**
   - A **Basic correction** checkbox in the New project step, default off.
   - When on, `new_project` samples the assembly timeline after the color step (fills the cache) and stores
     `"basic_correction": true` in `davigen.json`.
6. **Assign groups & nodes:** when the project has it on, run the write step for the items that just got their node
   structure, using the cache and sampling only what is missing.
7. **Menu entry:**
   - `resolve_menu/davigen_basic.py.template`, installed next to `davigen.py` by `install.sh` and removed by
     `uninstall.sh`.
   - It starts davigen with the UI opened to Basic Correction for the current timeline (`serve(..., start="basic")`
     plus a URL hash).
8. **Docs:**
   - `README.md` gets a new row in "What it does" and the new menu entry in the table of files outside the folder.
   - `docs/WORKFLOW.md` §5 Grading: how to use it, versions, markers.

## Tests

- Config defaults when the section is missing.
- `/api/basic` refuses while another job runs.
- The installer test, if any: both menu files are written and removed.

## Done when

A new project with the checkbox on, and an existing project with the button, both end with `DAVIGEN_AUTO`
versions, markers and a readable report.
