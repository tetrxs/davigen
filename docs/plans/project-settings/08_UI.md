# 08 · UI and menu entry

**Goal:** everything from steps 03–07 is usable in davigen's UI and from Resolve's Scripts menu (concept §7.1, §9).

**References:**

- the React app in `web/` (built into `davigen/ui/`), the Basic Correction pages as the pattern
- [`resolve_menu/davigen_basic.py.template`](../../../resolve_menu/davigen_basic.py.template),
  [`install.sh`](../../../install.sh), [`uninstall.sh`](../../../uninstall.sh)
- [`davigen/server.py`](../../../davigen/server.py) routes; `scripts/dev_server.py` for the UI against the fake
  Resolve

## How it is developed

1. **New project wizard:**
   - Review step: *Resolve settings: all automatic*, or *One-time setup needed for 25 fps* with a guide (step 03)
     that waits for Resolve and ticks off when done
   - a *Make proxies* checkbox with the estimate (count, size, time)
   - the run's summary: the check's result instead of *Left to do in Resolve*, and *Tips*
2. **Home screen:**
   - a *Project health* card: traffic lights per area (settings, proxies, media), a *Check project* button
   - a proxy panel: progress, *Stop*, *Resume*, sizes (made / originals), *Check proxies*
3. **Check page:** the report grouped by area, rows with light, now → after, instructions, *Check again*; the
   selection of fixes; *Repair* with its confirmation (what changes, where the backup goes); *Undo last repair*;
   orphans with sizes and *Move to Trash*.
4. **Menu entry:** `resolve_menu/davigen_check.py.template` → `davigen Check Project.py`, installed and removed like
   the Basic Correction one; it opens davigen on the check page.
5. **Docs:** README (the new menu entry in the table of files outside the folder, screenshots), WORKFLOW.

## How it is checked

- `tests/test_ui_backend.py`: the new routes against the fake Resolve (report, repair with and without
  confirmation, proxy progress, stop).
- `scripts/dev_server.py --open`: every state of the check page and the proxy panel with the fake, by eye.
- **In Resolve:** the menu entry opens the check page; the wizard's one-time setup works end to end. Written down
  under *Result*.
