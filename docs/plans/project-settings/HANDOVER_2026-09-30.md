## What stood out

- **Most key names are unverified.** Only the keys davigen uses today are known to work (`timelineFrameRate`,
  resolution, colour management, input scaling, gallery location). LUT interpolation, resize filter, audio sample
  rate, cache and proxy formats and both working-folder locations must come from the spike's `GetSetting()` dump.
- **Tetrahedral LUT interpolation touches Basic Correction.** Its simulator applies LUTs trilinearly and matches
  Resolve within 0.3–0.5 %. Switching projects to tetrahedral without the simulator would silently worsen Basic
  Correction (concept §4.4).
- **`03_WORK/OPTIMIZED_MEDIA` is probably never used:** Resolve writes optimized media into the cache location, as
  far as known. The spike confirms it (question 9).
- **The size guard will trip on high-frame-rate 4K.** A ½ ProRes Proxy of a DJI 4K 59.94 clip is about 90 Mb/s by
  Apple's figures, likely above 50 % of the HEVC original. What should happen then is question 3.
- **Add footage only accepts video files today** (`scanner.VIDEO_EXT`), and Edit assist imports music from wherever
  it sits. The audio check (§8.1) therefore needs a way in for audio files first.
- **ffmpeg becomes required** for proxies and audio conversion (today it is optional, for Edit assist). Proxies
  want `prores_videotoolbox`, audio wants soxr; Homebrew's ffmpeg has both (question 6).
- The MARSEILLE figures don't quite agree: 170 GB of proxies for 43 GB is 4×, "each proxy about twice its original"
  is 2×. Step 09's *before* measurement settles it.
- Resolve's *Create Timeline Backup* isn't in the scripting API as far as known; the concept backs up with
  `ExportProject` instead.
