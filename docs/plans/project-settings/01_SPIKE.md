# 01 · API spike in Resolve

**Goal:** answer §3 and §5 of the [concept](../../concepts/PROJECT_SETTINGS.md) on the real Resolve 21, Free and,
if available, Studio, before anything else is built. The result is one table: per setting *API / template / preset
/ manual only*, and the answers about proxies, backups and audio.

## How it is developed

One script, `scripts/spike_project_settings.py`, run from **Workspace → Scripts**, output to the console and to
`~/Movies/davigen_spike/project_settings/report.txt` plus `settings_<edition>_<project>.json` (the full
`GetSetting()` dump). It works in its own Project Manager folder `ZZ_DAVIGEN_SPIKE` and its own projects
`ZZ_SPIKE_SETTINGS_*`. It never deletes a project; they are left for you to delete by hand.

It runs in parts, because some checks need a restart or a click in between. Each part is a function selected by a
small file `~/Movies/davigen_spike/project_settings/next.txt` that the previous part writes, so starting the script
again continues where it left off.

## What it checks

| # | Check | Answers |
|---|---|---|
| 1 | Version, edition; `GetSetting()` without argument on a fresh project and on the open project (MARSEILLE copy), saved as JSON | the full key list, today's values on MARSEILLE |
| 2 | For every setting in concept §3: `SetSetting` return value, `GetSetting` after, value after `SaveProject` → load another project → `LoadProject` | *API* column |
| 3 | Playback frame rate variants: `"25"`, `"25.0"`, `25`; before and after `timelineFrameRate`; after a save; `Timeline.SetSetting` with `useCustomSettings` | whether any API form works |
| 4 | Cache location and proxy location: set, save, reload, read; with and without a trailing slash; path created before or after | whether the reset seen before is reproducible, and why |
| 5 | Presets: `GetPresetList()` output; `SetPreset("DAVIGEN_SPIKE_25")` on a fresh project (you create that preset by hand beforehand, with playback 25 and tetrahedral) | *preset* column; what a preset carries |
| 6 | Template: you set playback 25 and tetrahedral in `ZZ_SPIKE_SETTINGS_TEMPLATE` by hand; the script exports it (`ExportProject`) and imports it as a new project (`ImportProject(path, name)`), then reads every setting | *template* column; whether the import lands in the current Project Manager folder |
| 7 | Where optimized media and render cache files land (with a cache location set) | question 9 |
| 8 | Proxies: the script makes a ½ and a non-integer (1920 long edge) ProRes 422 Proxy of one 6K clip with ffmpeg, imports the clip into a scratch bin, `LinkProxyMedia`, reads `GetClipProperty()` (all keys, looking for `Proxy`, `Proxy Media Path`), `UnlinkProxyMedia`, links again; on a clip that has a Resolve-made proxy, whether `LinkProxyMedia` replaces it | linking in Free, clip properties, replacing foreign links |
| 9 | After a Resolve restart (part 2): are the links still there? | persistence |
| 10 | Frame accuracy and colour: frame *n* of original and proxy, both decoded by ffmpeg at the same small size, compared at five positions (mean difference in code values, and the best-matching offset in frames) | proxy matches the original, log stays log |
| 11 | Render with proxies linked and *Prefer proxies* on: a TIFF snippet render as Basic Correction does it, compared with the same render with proxies unlinked | renders read originals |
| 12 | `ExportProject(name, path, False)` to a scratch `02_BACKUPS`: time and size; any API call for a timeline backup | backups for §7.4 |
| 13 | Audio: imports a 44.1 kHz FLAC with cover, the same without cover, a 44.1 kHz WAV and a 48 kHz WAV (generated by ffmpeg); prints the clip properties Resolve reports; you listen on the Edit page | the cause of MARSEILLE #4 |
| 14 | Clip properties Resolve gives for video clips (`FPS`, `Video Codec`, `Resolution`, `Bit Depth`, `Sample Rate`, …) | whether §8 can use Resolve's values instead of ffprobe |
| 15 | Whether Resolve's preference files are readable text (listing only, nothing is changed) | proposal 4.5 c |

## What to do by hand

- Before part 1: make a copy of MARSEILLE_2026 with `dev_project_copy.py` and open it.
- Before part 5: in any project, Project Settings → set playback 25 and 3D LUT interpolation Tetrahedral → Presets →
  Save As `DAVIGEN_SPIKE_25`.
- Part 6: the script tells you what to set in the template project and waits.
- Part 9: quit and restart Resolve, open the copy, run the script again.
- Part 13: listen to the four audio clips on the Edit page, and write down which crackle.

## How it is checked

- `report.txt` and the JSON dumps are back in the repo discussion, and the result table is written into §3 and §5.5
  of the concept (as §12 of the Basic Correction concept holds its spike answers).
- Steps 02–07 are updated where the answers change them.
- **Stop point:** if `LinkProxyMedia` doesn't work in Free, or the links don't survive a restart, step 05 is
  re-planned before anything is built.
